# StridePilot Coach Policy

This note captures the current coach philosophy behind the engine hardening work.

It is not a product spec and not a full design doc. Its job is to make the current
guardrails easy to preserve when future engine changes are made.

## Core Direction

- Beginners should feel safe, but not passive.
- Workouts should feel like real running training, not filler.
- Walking is a tool for confidence, control, and pacing. It is not the main experience.
- Stronger runners should be recognized early.
- Early progression should feel smooth and credible.
- Workout structure should read clearly to a coach reviewing it.

## Beginner Principles

- No passive starts:
  Opening walk should stay short and purposeful.

- Meaningful running:
  Even the weakest run-walk sessions need enough real running that the runner can feel,
  "I ran today."

- Visible main set:
  Short easy/recovery sessions still need a clear start, main part, and finish.

- Walking frame should stay light:
  Easy and long runs should not feel like walking wrapped around a run.

## Stronger-Runner Opening Principles

- Opening weeks should not flatten everyone into the same cautious shape.
- Runners with real base or improvement intent should see an early but controlled quality signal.
- Specificity should arrive early enough to feel intentional, but not so early that week 1 becomes aggressive.

## Early Load Progression Principles

- Week 1 -> 2 should feel coached, not jumpy.
- Partial first weeks should not create fake-looking spikes in week 2.
- Smooth early load matters as much as plausible individual sessions.

## Progression Workout Principles

- A progression run should read as:
  calm opening -> build -> stronger finish -> short clean cooldown

- It should not read as:
  a vague easy run with a technical label

- The final stronger block should be distinct and controlled, not a long muddled tail.

## Practical Rule For Future Changes

If a future change makes a scenario feel:

- more passive,
- less coach-like,
- less specific for stronger runners,
- or more technically awkward to review,

then it is likely moving away from the current StridePilot direction.
